# Wish List Tracker

Keep the surprise. Skip the duplicates.

A public learning project built with Django + HTMX. The goal is a small, server-rendered wishlist app where a recipient can maintain a list while other people can secretly claim gifts to avoid duplicates.

## Planned MVP

- Create wish lists for occasions such as birthdays and Christmas
- Add, edit, and remove wishlist items
- Claim an item without revealing the claimant to the recipient
- Show other shoppers that an item is already claimed
- Keep the interface server-rendered and progressively enhanced with HTMX

## Stack

- Python
- Django
- HTMX
- SQLite for local development

PostgreSQL can replace SQLite when the app is deployed.
